# Social Book

Проект для учебной практики по фронтенд-разработке. За основу взяла [макет Social Book в Figma](https://www.figma.com/design/p4jDYcwlRsEVihOixcleWQ/Social-Book?node-id=1-4). Для мобильных экранов адаптировала расположение полей и кнопок.

## Что можно делать

- Добавлять, редактировать и удалять посты.
- Открывать и скрывать комментарии к каждому посту.
- Добавлять и удалять комментарии. Их количество на карточке обновляется сразу.

Приложение открывается с примером поста и двумя комментариями. После перезагрузки страницы список возвращается к исходному состоянию.

## Как запустить

В папке проекта выполни:

```bash
npm ci
npm run dev
```

Открой адрес, который Vite покажет в строке `Local`. Для сборки проекта выполни `npm run build`. Результат появится в папке `dist`.

## Что внутри

- `src/app/store.js` — подключение хранилища Redux Toolkit.
- `src/features/posts/postsSlice.js` — начальные данные и действия для постов и комментариев.
- `src/features/posts/` — React-компоненты карточки поста, формы ввода и окна редактирования. Одна и та же форма используется для добавления постов и комментариев.
- `src/index.css` — стили ленты, карточек и окна редактирования, включая мобильную версию.
